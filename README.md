# RoboCupJunior Rescue Simulation – Egypt 2025 🇪🇬🤖
This repository contains the complete source code and resources for our participation in the **RoboCupJunior Rescue Simulation** competition held in Egypt 2025, where our team proudly achieved **2nd place (First Runner-Up)** 🥈.

## 📌 About the Competition
The RoboCupJunior Rescue Simulation is a prestigious AI and robotics contest that challenges students to build a fully autonomous rescue robot using Python. The robot must intelligently explore a digital maze, detect victims and hazards using computer vision, and submit its findings while scoring maximum points within a time limit.

## 🎯 Project Objectives
- Design an intelligent robot that navigates using sensors (LiDAR, GPS, Camera).
- Implement **path planning**, **tile tracking**, and **exploration algorithms**.
- Detect **victims and hazards** using custom image recognition models.
- Submit the final **map and findings** using encoded messages.
- Compete in a virtual simulation platform (Erebus/Webots) under official RoboCup rules.

## 🧠 Features
- Fully modular Python-based architecture.
- Robust SLAM logic for maze exploration.
- Custom victim/hazard detection using OpenCV and HSV/contour filters.
- Real-time emitter and scoring integration.
- GPS-based visited tile logging for scoring strategy.
